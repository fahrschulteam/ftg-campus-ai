# FTG Campus AI – Sprint 2

## Neu
- Projektsuche über Name, Ziel, Zielgruppe, Region und Tags
- Filter für Favoriten und Status
- Sortierung nach Priorität, Fortschritt und Name
- Favoriten mit Sternmarkierung
- Prioritäten: Normal, Mittel, Hoch
- frei definierbare Tags
- erweiterter Projektdialog
- Speicherung weiterhin lokal im Browser

## Installation
1. Inhalt dieses Ordners in den bestehenden Ordner `ftg-campus-ai` kopieren.
2. Vorhandene Dateien ersetzen.
3. Im VS-Code-Terminal `npm install` ausführen.
4. Danach `npm run dev` starten.
